- 不納入 DerivedData、`*.noindex`、`.build`、`node_modules`、下載的 `.iinaplgz`、Finder 中繼檔或個人 Xcode 設定。
- 保留原始碼、`Package.resolved`、`package-lock.json` 與共用工程設定。

- 每次完成工作後，在 [工作記錄](../history/WORK_LOG.md) 追加一筆日期、工作內容、實際驗證與未驗證／限制；保留既有記錄，不以計畫冒充成果。
- 記錄同樣遵守上述日誌保密要求，不寫入憑證或完整簽名串流 URL。
