# 文件查詢（Context7）

涉及函式庫、框架、SDK、API、CLI 或雲端服務的語法、配置、遷移、專屬除錯或用法時，使用 Context7 查詢目前文件，優先於一般網頁搜尋。一般重構、自行編寫腳本、業務邏輯除錯、程式碼審查與通用程式概念不需要查詢。

1. 先使用 `resolve-library-id`，提供名稱與具體查詢目的；使用者已給 `/org/project` ID 時可略過。
2. 依名稱、描述、片段數、來源信譽與評分選擇；結果不符時更換名稱或查詢。有指定版本時使用對應版本 ID。
3. 用 `query-docs` 查詢單一概念；不同概念分開查詢，只有探討互動時合併。
4. 根據查得文件回答。
